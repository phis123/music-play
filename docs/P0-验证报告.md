## 1. Web UI 与内核（未通过）

### 1.1 pywebview + pythonnet：不可用

| 现象 | 原因 |
|---|---|
| `PYTHONNET_RUNTIME=netfx` → `Failed to resolve Python.Runtime.Loader.Initialize` | pythonnet 3.2.1 已不再支持该 .NET Framework 加载路径 |
| `PYTHONNET_RUNTIME=coreclr` → 缺 `System.Windows.Forms` | coreclr 默认只加载 NETCore.App，需指定 WindowsDesktop 运行时配置 |
| 指定 `PYTHONNET_CORECLR_RUNTIME_CONFIG`（WindowsDesktop.App 8.0）→ WinForms 可加载 | ✅ 这一步能过 |
| 但 `import webview.platforms.winforms` → `cannot import name 'SystemEvents'` | pywebview 的 WinForms 后端与 pythonnet 3.2.1 + .NET 8 反射不兼容 |

**判断**：pywebview 依赖 .NET，且与新版 pythonnet 存在兼容裂缝，不适合作为分发基础。

### 1.2 PySide6：可用，但没有 WebEngine

- PySide6 6.12.0（Essentials 78MB + Addons 39MB）安装正常
- `QtWidgets`、`QtMultimedia` 均可用
- ❌ Addons 已不含 QtWebEngine（`Qt6WebEngineCore.dll` 不存在），即没有内置 Chromium

### 关键发现：miniaudio 不支持中文路径

```
miniaudio.decode_file("...\晴天\001-晴天.mp3")   → DecodeError(-7)
miniaudio.decode_file("...\_ascii_test.mp3")      → OK
```

**解决方案**（已验证）：先 `open(path,'rb').read()` 读成 bytes，再用 `miniaudio.decode(raw)` / `miniaudio.stream_memory(raw)`。
中文路径完全正常，代价是整首读入内存（单曲 5~10MB，可接受）。

## 3. 打包（通过）

```powershell
pyinstaller --onedir --console --hidden-import _cffi_backend audio_probe.py
```

- 产物：89 个文件 / 54 MB（仅含 miniaudio，未含 Qt）
- 脱离 Python 独立运行 ✅

### 两个必须记住的打包坑

1. `_cffi_backend` 要手动 `--hidden-import`，否则 exe 启动即 `ModuleNotFoundError`
2. 打包后控制台是 GBK，`PYTHONIOENCODING` 无效，必须在代码里
   `sys.stdout.reconfigure(encoding='utf-8', errors='replace')`，否则打印 `✓/✗` 直接崩溃

## 4. 待决事项

「Web UI + 自带内核」这条路线需要换壳，二选一：

| 方案 | 内核 | 体积 | 语言栈 | 备注 |
|---|---|---|---|---|
| A. Electron | 自带 Chromium | ~180MB | Node + 可选 Python 侧车 | UI 生态最成熟，打包工具完善 |

miniaudio（方案 B）与 Chromium `<audio>`（方案 A）都能覆盖 MP3/FLAC/WAV/OGG。
