## 踩坑记录（都已解决，写进代码/文档）

### 1. Electron 不能从 DSH 工作区目录运行 ⚠️

```
E:\dsh\work2\...\p1-electron  → 崩溃，退出码 -2147483645 (0x80000003)
E:\etest                      → 正常运行
C:\Temp\etest                 → 正常运行
```

同一块磁盘、同一份二进制（SHA256 与官方一致），只有 DSH 工作区路径下崩。
推测是沙箱给工作区加的 ACL 让 Chromium 初始化失败。

**结论**：开发/测试时把工程复制到工作区外（如 `E:\etest`）运行，或最终打包成 exe 后分发。

### 2. pnpm 的软链结构不可复制

`node_modules` 用 pnpm 默认（符号链接）布局时，robocopy 复制到别处会断链，
表现为 `Cannot find package 'debug'`。

**解决**：在项目根放 `.npmrc` → `node-linker=hoisted`（扁平结构，可整体复制）。

### 3. pnpm v10+ 默认阻止 postinstall

Electron 的二进制不会被下载（只有 3KB 的占位包）。
**解决**：手动执行 `node node_modules/electron/install.js`，或 `pnpm approve-builds`。

### 4. `ELECTRON_RUN_AS_NODE=1` 环境变量

某些宿主环境（如 DSH 自身）会注入该变量，Electron 会退化成普通 Node 运行，
表现为 `require('electron')` 返回字符串、`app` 为 undefined。
**解决**：启动前清除该环境变量。

### 5. music-metadata v12 是纯 ESM

`require('music-metadata')` 会抛 `ERR_REQUIRE_ESM`。
**解决**：`const mm = await import('music-metadata')`。

### 6. Electron 是 GUI 子系统程序

控制台拿不到 `console.log` 输出，调试要把结果写文件。
